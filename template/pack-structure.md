## Rules

- TOC at top
- Quick revision near end
- Index last
- Sections numbered §Unit.Section
- Source tags inline
- Companion file `pack.meta.json` holds structured metadata (see `pack-meta.md`)
- Optional visual style for PDF/DOCX output: see `render-style.md`
